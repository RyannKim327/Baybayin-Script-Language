## 🚀 Basic Usage & Tutorials / Gabay sa Paggamit [Developer/Contributor]

**Kalawang** (ᜃᜎᜏᜅ᜔) is a programming language engine written in Rust that supports both standard Tagalog keywords and authentic Unicode Baybayin script (`U+1700`..`U+171F`).

### 📦 Prerequisites & Installation

To build and run Kalawang, you need [Rust](https://www.rust-lang.org/) installed (Rust 2024 edition or standard stable rustc/cargo).

1. Clone the repository and navigate into the project directory:
   ```bash
   git clone https://github.com/RyannKim327/Baybayin-Script-Language.git
   cd kalawang
   ```

2. Build the project using Cargo:
   ```bash
   cargo build --release
   ```

3. Run unit tests to verify your setup:
   ```bash
   cargo test
   ```

---

### 💻 How to Run Kalawang Scripts

Kalawang source code files typically use `.bay` extensions.

Run any source file using `cargo run`:
```bash
cargo run -- examples/tagalog/hello.bay
```

Or execute the built binary directly:
```bash
./target/release/kalawang examples/tagalog/hello.bay
```

## 🎓 Basic Tutorials / Gabay sa Paggamit

#### 1. Print Functions / Pagpapahayag (Output)
> **Tagalog**: Ang `sabihin`, o `ipaliwanag` ay ginagamit upang maglathala o magpakita ng mensahe at datos sa terminal o screen.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜐᜊᜒᜑᜒᜈ᜔`᜵ ᜂ `ᜁᜉᜎᜒᜏᜈᜄ᜔`᜵ ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜋᜄ᜔ᜎᜆ᜔ᜑᜎ ᜂ ᜋᜄ᜔ᜉᜃᜒᜆ ᜈᜅ᜔ ᜋᜒᜈ᜔ᜐᜑᜒ ᜀᜆ᜔ ᜇᜆᜓᜐ᜔ ᜐ ᜆᜒᜇ᜔ᜋᜒᜈᜎ᜔᜶
> **English**: The `print`, `say`, or `tell` keywords are used to display messages and data output to the terminal or screen.

**Halimbawa / Example**
```kalawang
// Tagalog
sabihin("Kamusta, Mundo!");
ipaliwanag "Mensahe mula sa Kalawang";

// English
print("Hello, World!");
say "Message from Kalawang";
```

#### 2. Variables / Mga Lalagyanan ng Datos
> **Tagalog**: Ang `si`, `ang`, o `ipangalan` ay ginagamit upang magdeklara ng lalagyanan (variable) para sa iba't ibang uri ng datos tulad ng bilang, salita, boolean, at array.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜐᜒ`᜵ `ᜀᜅ᜔`᜵ ᜂ `ᜁᜉᜅᜎᜈ᜔`᜵  ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜋᜄ᜔ᜇᜒᜃ᜔ᜎᜇ ᜈᜅ᜔ ᜎᜎᜄ᜔ᜌᜈᜈ᜔ ᜉᜇ ᜐ ᜁᜊ'ᜆ᜔ ᜁᜊᜅ᜔ ᜂᜇᜒ ᜈᜅ᜔ ᜇᜆᜓᜐ᜔ ᜆᜓᜎᜇ᜔ ᜈᜅ᜔ ᜊᜒᜎᜅ᜔᜵ ᜐᜎᜒᜆ᜵ ᜊᜓᜂᜎᜒᜀᜈ᜔᜶
> **English**: The `that` keywords are used to declare variables that store values such as numbers, strings, booleans, and arrays.

**Halimbawa / Example**
```kalawang
// Tagalog
si pangalan = "Maynila";
ipangalan edad = 2026;
si suma = 15 + 25;

sabihin pangalan;
sabihin edad;
sabihin suma;

// English
that name = "Manila";
that age = 2026;
that sum = 15 + 25;

print name;
print age;
print sum;
```

#### 3. Assignment Operators / Pagpapasa ng Nilalaman
> **Tagalog**: Ang `ay`, o `=` ay ginagamit upang maglagay o magtalaga ng halaga sa isang variable.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜀᜌ᜔`᜵ ᜂ `=` ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜋᜄ᜔ᜎᜄᜌ᜔ ᜂ ᜋᜄ᜔ᜆᜎᜄ ᜈᜅ᜔ ᜑᜎᜄ ᜐ ᜁᜐᜅ᜔ ᜊᜇᜒᜀᜊ᜔ᜎᜒ᜶
> **English**: The `is`, or `=` operators are used to assign or update values stored within variables.

**Halimbawa / Example**
```kalawang
// Tagalog
si lungsod ay "Maynila";
si taon = 2026;

lungsod ay "Quezon";
sabihin lungsod;

// English
that city is "Manila";
that year = 2026;

city is "Quezon";
print city;
```

#### 4. User Input / Pagkuha ng Input
> **Tagalog**: Ang `pahingi` ay ginagamit upang humingi o tumanggap ng datos mula sa gumagamit (user input).
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜉᜑᜒᜅᜒ` ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜑᜓᜋᜒᜅᜒ ᜂ ᜆᜓᜋᜅ᜔ᜄᜉ᜔ ᜈᜅ᜔ ᜇᜆᜓᜐ᜔ ᜋᜓᜎ ᜐ ᜄᜓᜋᜄᜋᜒᜆ᜔᜶
> **English**: The `ask` function is used to prompt the user and receive input from the terminal.

**Halimbawa / Example**
```kalawang
// Tagalog
si pangalan = pahingi("Anong pangalan mo? ");
sabihin ("Kamusta, " + pangalan + "!");

// English
that name = ask("What is your name? ");
print ("Hello, " + name + "!");
```

#### 5. Type Conversion / Pagpapalit ng Uri ng Datos
> **Tagalog**: Ang `isalin` ay ginagamit upang baguhin ang uri ng datos (data type) ng isang halaga, tulad ng pagsasalin mula teksto patungong bilang (`numero`), desimal (`hatian`), salita (`salita`), boolean (`booleano`), o listahan (`mga`/`array`).
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜁᜐᜎᜒᜈ᜔` ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜊᜄᜓᜑᜒᜈ᜔ ᜀᜅ᜔ ᜂᜇᜒ ᜈᜅ᜔ ᜇᜆᜓᜐ᜔ (datatype) ᜈᜅ᜔ ᜁᜐᜅ᜔ ᜑᜎᜄ᜵ ᜆᜓᜎᜇ᜔ ᜈᜅ᜔ ᜉᜄ᜔ᜐᜐᜎᜒᜈ᜔ ᜋᜓᜎ ᜆᜒᜃ᜔ᜐ᜔ᜆᜓ ᜉᜆᜓᜅᜓᜅ᜔ ᜊᜒᜎᜅ᜔᜵ ᜇᜒᜐᜒᜋᜎ᜔᜵ ᜐᜎᜒᜆ᜵ ᜊᜓᜂᜎᜒᜀᜈ᜔᜵ ᜂ ᜎᜒᜐ᜔ᜆᜑᜈ᜔᜶
> **English**: The `convert` built-in function is used to cast or convert a value into a specified target datatype (`int`, `float`/`decimal`, `string`, `bool`/`boolean`, `array`/`list`).

**Halimbawa / Example**
```kalawang
// Tagalog
si teksto = "100";
si bilang_na_numero = isalin(teksto, numero);
si kabuuan = bilang_na_numero + 50;
sabihin ("Kabuuan: " + kabuuan);

si desimal = isalin("3.14", hatian);
si totoo = isalin("tama", bool);

// English
that text = "100";
that parsed_number = convert(text, int);
that total = parsed_number + 50;
print ("Total: " + total);

that decimal_val = convert("3.14", float);
that is_valid = convert("true", bool);
```

#### 6. Conditionals (If / Else If / Else) / Pagsusuri ng Kondisyon
> **Tagalog**: Ginagamit ang `kung`, `okaya` / `ukaya` / `malibankung`, at `kundi` / `kunghindi` upang magsagawa ng iba't ibang bahagi ng code batay sa katotohanan ng kondisyon.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜀᜅ᜔ `ᜃᜓᜅ᜔`᜵ `ᜂᜃᜌ` / `ᜂᜃᜌ` / `ᜋᜎᜒᜊᜈ᜔ᜃᜓᜅ᜔`᜵ ᜀᜆ᜔ `ᜃᜓᜈ᜔ᜇᜒ` / `ᜃᜓᜅ᜔ᜑᜒᜈ᜔ᜇᜒ` ᜂᜉᜅ᜔ ᜋᜄ᜔ᜐᜄᜏ ᜈᜅ᜔ ᜁᜊ'ᜆ᜔ ᜁᜊᜅ᜔ ᜊᜑᜄᜒ ᜈᜅ᜔ code ᜊᜆᜌ᜔ ᜐ ᜃᜆᜓᜆᜓᜑᜈᜈ᜔ ᜈᜅ᜔ ᜃᜓᜈ᜔ᜇᜒᜐ᜔ᜌᜓᜈ᜔᜶
> **English**: Conditional branching uses `if`, `elseif`, and `else` to control program flow based on boolean expressions.

**Halimbawa / Example**
```kalawang
// Tagalog
si marka = 85;

kung (marka >= 90) {
    sabihin "Napakagaling!";
} okaya (marka >= 75) {
    sabihin "Pumasa!";
} kundi {
    sabihin "Kailangang mag-aral pa.";
}

// English
that grade = 85;

if (grade >= 90) {
    print "Excellent!";
} elseif (grade >= 75) {
    print "Passed!";
} else {
    print "Need to study more.";
}
```

#### 7. Loops (While Loop) / Paulit-ulit na Pagpapatupad
> **Tagalog**: Ang `habang` ay ginagamit upang ulit-ulitin ang pagpapatupad ng isang bahagi ng code hangga't totoo ang ibinigay na kondisyon.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜀᜅ᜔ `ᜑᜊᜅ᜔` ᜀᜌ᜔ ᜄᜒᜈᜄᜋᜒᜆ᜔ ᜂᜉᜅ᜔ ᜂᜎᜒᜆ᜔-ᜂᜎᜒᜆᜒᜈ᜔ ᜀᜅ᜔ ᜉᜄ᜔ᜉᜉᜆᜓᜉᜇ᜔ ᜈᜅ᜔ ᜁᜐᜅ᜔ ᜊᜑᜄᜒ ᜈᜅ᜔ ᜃᜓᜇᜒ ᜑᜅ᜔ᜄ'ᜆ᜔ ᜆᜓᜆᜓᜂ ᜀᜅ᜔ ᜁᜊᜒᜈᜒᜄᜌ᜔ ᜈ ᜃᜓᜈ᜔ᜇᜒᜐ᜔ᜌᜓᜈ᜔᜶
> **English**: The `while` loop repeatedly executes a block of code as long as the specified condition remains true.

**Halimbawa / Example**
```kalawang
// Tagalog
si bilang = 1;

habang (bilang <= 5) {
    sabihin ("Bilang: " + bilang);
    bilang = bilang + 1;
}

// English
that count = 1;

while (count <= 5) {
    print ("Count: " + count);
    count = count + 1;
}
```

#### 8. Arrays & Lists / Mga Listahan at Koleksyon
> **Tagalog**: Maaaring gumawa ng mga listahan gamit ang bracket `[]` o ang `mga(...)` / `bilang(...)`. Sinusuportahan ang pagkuha ng elemento gamit ang positibong index (`arr[0]`), negatibong lalagayan mula sa dulo (`arr[-1]`), at pagbabago ng elemento (`arr[0] = bago`).
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜋᜀᜀᜇᜒᜅ᜔ ᜄᜓᜋᜏ ᜈᜅ᜔ ᜋᜅ ᜎᜒᜐ᜔ᜆᜑᜈ᜔ ᜄᜋᜒᜆ᜔ ᜀᜅ᜔ ᜊ᜔ᜇᜃ᜔ᜃᜒᜆ᜔ `[]` ᜂ ᜀᜅ᜔ `ᜋᜅ(...)` / `ᜊᜒᜎᜅ᜔(...)`᜶ ᜐᜒᜈᜓᜐᜓᜉᜓᜇ᜔ᜆᜑᜈ᜔ ᜀᜅ᜔ ᜉᜄ᜔ᜃᜓᜑ ᜈᜅ᜔ ᜁᜎᜒᜋᜒᜈ᜔ᜆᜓ ᜄᜋᜒᜆ᜔ ᜀᜅ᜔ ᜉᜓᜐᜒᜆᜒᜊᜓᜅ᜔ ᜁᜈ᜔ᜇᜒᜃ᜔ᜐ᜔ (`arr[0]`)᜵ ᜈᜒᜄᜆᜒᜊᜓᜅ᜔ ᜎᜎᜄᜌᜈ᜔ ᜋᜓᜎ ᜐ ᜇᜓᜎᜓ (`arr[-1]`)᜵ ᜀᜆ᜔ ᜉᜄ᜔ᜊᜊᜄᜓ ᜈᜅ᜔ ᜁᜎᜒᜋᜒᜈ᜔ᜆᜓ (`arr[0] = ᜊᜄᜓ`)᜶
> **English**: Arrays and lists can be created using bracket syntax `[]` or constructors `list(...)` / `array(...)`. Kalawang supports 0-based indexing (`arr[0]`), negative indexing from the end (`arr[-1]`), and in-place element modification (`arr[0] = new_value`).

**Halimbawa / Example**
```kalawang
// Tagalog
si mga_prutas = ["mangga", "saging", "pinya"];
si unang_prutas = mga_prutas[0];
si huling_prutas = mga_prutas[-1];

mga_prutas[1] = "bayabas";
sabihin mga_prutas;

// English
that fruits = ["mango", "banana", "pineapple"];
that first_fruit = fruits[0];
that last_fruit = fruits[-1];

fruits[1] = "guava";
print fruits;
```

#### 9. Built-in Functions / Mga Karaniwang Tungkulin sa Array at String
> **Tagalog**: Mayroong mga built-in functions para sa arrays at strings tulad ng `haba`/`sukat`, `dagdagan`/`idagdag`, `alisin`/`tanggalin`, `nandyan`/`mayroon`, `pagsamahin`, at `baligtad`.
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜋᜌ᜔ᜇᜓᜂᜅ᜔ ᜋᜅ ᜊᜓᜁᜎ᜔ᜆ᜔-ᜁᜈ᜔ ᜉᜓᜈ᜔ᜃ᜔ᜆᜒᜂᜈ᜔ᜐ᜔ ᜉᜇ ᜐ ᜀᜇ᜔ᜇᜌ᜔ᜐ᜔ ᜀᜆ᜔ ᜐ᜔ᜆ᜔ᜇᜒᜅ᜔ᜐ᜔ ᜆᜓᜎᜇ᜔ ᜈᜅ᜔ `ᜑᜊ`/`ᜐᜓᜃᜆ᜔`᜵ `ᜇᜄ᜔ᜇᜄᜈ᜔`/`ᜁᜇᜄ᜔ᜇᜄ᜔`᜵ `ᜀᜎᜒᜐᜒᜈ᜔`/`ᜆᜅ᜔ᜄᜎᜒᜈ᜔`᜵ `ᜈᜈ᜔ᜇ᜔ᜌᜈ᜔`/`ᜋᜌ᜔ᜇᜓᜂᜈ᜔`᜵ `ᜉᜄ᜔ᜐᜋᜑᜒᜈ᜔`᜵ ᜀᜆ᜔ `ᜊᜎᜒᜄ᜔ᜆᜇ᜔`᜶
> **English**: Kalawang provides built-in utilities for manipulating arrays and strings: `length`/`len`/`count`/`size`, `push`/`append`/`add`, `pop`/`remove`/`delete`, `contains`/`includes`, `join`, and `reverse`.

**Halimbawa / Example**
```kalawang
// Tagalog
si listahan = [10, 20, 30];

// Haba / Sukat
si kabuuang_sukat = haba(listahan);
sabihin ("Sukat: " + kabuuang_sukat);

// Pagdagdag ng elemento
dagdagan(listahan, 40);
sabihin listahan;

// Pag-alis ng huling elemento
si inalis = alisin(listahan);
sabihin ("Inalis: " + inalis);

// Pagsusuri kung nasa listahan
si meron_ba = nandyan(listahan, 20);
sabihin ("Nandyan ba ang 20: " + meron_ba);

// Pagsasama bilang string
si teksto = pagsamahin(listahan, " - ");
sabihin ("Pinagsama: " + teksto);

// Pagbabaligtad
si binaligtad = baligtad(listahan);
sabihin ("Binaligtad: " + binaligtad);

// English
that items = [10, 20, 30];

// Length / Size
that total_len = length(items);
print ("Length: " + total_len);

// Appending an element
append(items, 40);
print items;

// Removing the last element
that popped = pop(items);
print ("Popped: " + popped);

// Checking presence
that has_twenty = contains(items, 20);
print ("Contains 20: " + has_twenty);

// Joining into a string
that joined = join(items, " - ");
print ("Joined: " + joined);

// Reversing
that reversed_items = reverse(items);
print ("Reversed: " + reversed_items);
```

#### 10. Operators / Mga Operator
> **Tagalog**: Sinusuportahan ang matimatikong operasyon (`+`, `-`, `*`, `/`), paghahambing (`aytalagang` / `==` / `===`, `hindi` / `!=`, `<`, `<=`, `>`, `>=`),at lohikal na operasyon (`at` / `&&`, `o` / `||`).
> **ᜊᜌ᜔ᜊᜌᜒᜈ᜔**: ᜐᜒᜈᜓᜐᜓᜉᜓᜇ᜔ᜆᜑᜈ᜔ ᜀᜅ᜔ ᜋᜆᜒᜋᜆᜒᜃᜓᜅ᜔ ᜂᜉᜒᜇᜐ᜔ᜌᜓᜈ᜔ (`+`᜵ `-`᜵ `*`᜵ `/`)᜵ ᜉᜄ᜔ᜑᜑᜋ᜔ᜊᜒᜅ᜔ (`ᜀᜌ᜔ᜆᜎᜄᜅ᜔` / `==` / `===`᜵ `ᜑᜒᜈ᜔ᜇᜒ` / `᜶=`᜵ `<`᜵ `<=`᜵ `>`᜵ `>=`)᜵ ᜀᜆ᜔ ᜎᜓᜑᜒᜃᜎ᜔ ᜈ ᜂᜉᜒᜇᜐ᜔ᜌᜓᜈ᜔ (`ᜀᜆ᜔` / `&&`᜵ `ᜂ` / `||`)᜶
> **English**: Supports arithmetic operations (`+`, `-`, `*`, `/`), comparison operations (`isliterally` / `==` / `===`, `not` / `!=`, `<`, `<=`, `>`, `>=`), and logical operators (`and` / `&&`, `or` / `||`).

**Halimbawa / Example**
```kalawang
// Tagalog
si x = 10;
si y = 20;

si suma = x + y;
si ay_pantay = (x aytalagang y);
si lohikal = (x < y) at (y > 15);

sabihin ("Suma: " + suma);
sabihin ("Pantay ba: " + ay_pantay);
sabihin ("Lohikal: " + lohikal);

// English
that x = 10;
that y = 20;

that sum = x + y;
that is_equal = (x isliterally y);
that logical_check = (x < y) and (y > 15);

print ("Sum: " + sum);
print ("Equal: " + is_equal);
print ("Logical: " + logical_check);
```
