### Introduction (English)
> I started creating a programming language with the help of `Python Programming`.
In fact, the results were good and I somewhat liked some of them; however, it was merely translation and transliteration,
meaning it was still based on `Python` which is `space-sensitive`. I asked an `AI` or `Artificial Intelligence` something a bit unusual.
I replaced the former name `Sawa` (derived from the Tagalog word for `Python`) with `Kalawang`, which is Tagalog for `Rust`.
The result turned out much better for me because it became easier to use—it feels similar to `Visual Basic`,
without needing many **spaces** or being **space-sensitive** to run. I created this language not to show off, but simply to
test my capabilities and see if I could share `BAYBAYIN` with more people, not just in literature, but also in the world of technology.

## 🚀 Basic Usage & Tutorials / Gabay sa Paggamit

**Kalawang** (ᜃᜎᜏᜅ᜔) is a programming language engine written in Rust that supports both standard Tagalog keywords and authentic Unicode Baybayin script (`U+1700`..`U+171F`).

### 📦 Prerequisites & Installation

To build and run Kalawang, you need [Rust](https://www.rust-lang.org/) installed (Rust 2024 edition or standard stable rustc/cargo).

1. Clone the repository and navigate into the project directory:
   ```bash
   git clone https://github.com/RyannKim327/Baybayin-Script-Language.git
   cd kalawang
   ```

2. Build the project using Cargo:
   ```bash
   cargo build --release
   ```

3. Run unit tests to verify your setup:
   ```bash
   cargo test
   ```

---

### 💻 How to Run Kalawang Scripts

Kalawang source code files typically use `.bay` or `.kl` extensions.

Run any source file using `cargo run`:
```bash
cargo run -- examples/hello.bay
```

Or execute the built binary directly:
```bash
./target/release/kalawang examples/hello.bay
```

## 🎓 Basic Tutorials

### 1. Hello World (Paglimbag)

Print strings or values using `sabihin` or `ipaliwanag` (or `ᜐᜊᜒᜑᜒᜈ᜔` / `ᜁᜉᜎᜒᜏᜈᜄ᜔`). End statements with a Single Danda (`᜵`).

**Latin Tagalog:**
```kalawang
sabihin "Kamusta, Mundo!" ᜵
ipaliwanag "Maligayang pagdating sa Kalawang!" ᜵
```

**Baybayin Script:**
```kalawang
ᜐᜊᜒᜑᜒᜈ᜔ "Kamusta, Mundo!" ᜵
ᜁᜉᜎᜒᜏᜈᜄ᜔ "Maligayang pagdating sa Kalawang!" ᜵
```

---

### 2. Variables (Mga Baryabol)

Declare variables using `si` or `ipangalan` (or Baybayin `ᜐᜒ` / `ᜁᜉᜅᜎᜈ᜔`):

```kalawang
// Using Latin Tagalog
si pangalan = "Maynila" ᜵
ipangalan edad = 2026 ᜵

sabihin pangalan ᜵
sabihin edad ᜵

// Using Baybayin Script
ᜐᜒ a = 15 ᜵
ᜐᜒ b = 25 ᜵
ᜐᜒ suma = a + b ᜵

ᜐᜊᜒᜑᜒᜈ᜔ suma ᜵
```

---

### 3. Basic Operations & Expressions (Aritmetika at Pagsasama)

Kalawang supports addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), and string concatenation (`+`):

```kalawang
si x ay 10 ᜵
si y ay 20 ᜵
si kabuuan ay x + y ᜵

sabihin ("Ang kabuuan ay: " + kabuuan) ᜵
```

---

### 4. Conditionals (Mga Desisyon: `kung` / `okaya` / `kundi`)

Check conditions using `kung` (if), `okaya` (else if), and `kundi` (else). You can use curly braces `{}` or inline statements:

**Using Block Syntax `{}`:**
```kalawang
si suma = 40 ᜵

kung (suma > 30) {
    sabihin "Ang suma ay higit sa 30" ᜵
} okaya (suma === 30) {
    sabihin "Ang suma ay eksaktong 30" ᜵
} kundi {
    sabihin "Ang suma ay mas mababa sa 30" ᜵
}
```

**Using Baybayin Script:**
```kalawang
ᜐᜒ a = 15 ᜵
ᜐᜒ b = 25 ᜵

ᜃᜓᜅ᜔ (a < b) ᜐᜊᜒᜑᜒᜈ᜔ "Si a ay mas maliit kaysa kay b" ᜵ ᜂᜃᜌ (b > a) ᜐᜊᜒᜑᜒᜈ᜔ "Si a ay mas malaki kaysa kay b" ᜵ ᜃᜓᜈ᜔ᜇᜒ ᜐᜊᜒᜑᜒᜈ᜔ "Si a ay pantay kay b" ᜵
```

---

### 5. Loops (Mga Paulit-ulit: `habang`)

Repeat actions while a condition evaluates to `tama` (`true`):

```kalawang
si bilang = 1 ᜵

habang (bilang <= 5) {
    sabihin ("Bilang: " + bilang) ᜵
    bilang = bilang + 1 ᜵
}
```
