### Introduction (English)
> I started creating a programming language with the help of `Python Programming`.
In fact, the results were good and I somewhat liked some of them; however, it was merely translation and transliteration,
meaning it was still based on `Python` which is `space-sensitive`. I asked an `AI` or `Artificial Intelligence` something a bit unusual.
I replaced the former name `Sawa` (derived from the Tagalog word for `Python`) with `Kalawang`, which is Tagalog for `Rust`.
The result turned out much better for me because it became easier to use—it feels similar to `Visual Basic`,
without needing many **spaces** or being **space-sensitive** to run. I created this language not to show off, but simply to
test my capabilities and see if I could share `BAYBAYIN` with more people, not just in literature, but also in the world of technology.

## 🚀 Basic Usage & Tutorials / Gabay sa Paggamit

**Kalawang** (ᜃᜎᜏᜅ᜔) is a programming language engine written in Rust that supports both standard Tagalog keywords and authentic Unicode Baybayin script (`U+1700`..`U+171F`).

### 📦 Prerequisites & Installation

To build and run Kalawang, you need [Rust](https://www.rust-lang.org/) installed (Rust 2024 edition or standard stable rustc/cargo).

1. Clone the repository and navigate into the project directory:
   ```bash
   git clone https://github.com/RyannKim327/Baybayin-Script-Language.git
   cd kalawang
   ```

2. Build the project using Cargo:
   ```bash
   cargo build --release
   ```

3. Run unit tests to verify your setup:
   ```bash
   cargo test
   ```

---

### 💻 How to Run Kalawang Scripts

Kalawang source code files typically use `.bay` or `.kl` extensions.

Run any source file using `cargo run`:
```bash
cargo run -- examples/tagalog/hello.bay
```

Or execute the built binary directly:
```bash
./target/release/kalawang examples/tagalog/hello.bay
```

## 🎓 Basic Tutorials

1. `Sabihin`
> Ang kagamitan ng `sabihin` o `ᜐᜊᜒᜑᜒᜈ᜔` sa baybayin ay para ipakita, o ilathala ang kung ano ang nilalaman.

**Halimbawa**
```kalawang
// Tagalog
sabihin("Kamusta mundo");

// Baybayin
ᜐᜊᜒᜑᜒᜈ᜔("Kamusta Mundo")᜶
```

2. `Si`
> Ang `si` o `ᜐᜒ` sa baybayin ay ginagamit upang malaman kung sino ang isang bagay. Sa `Kalawang`, ginagamit naman ito upang paglagyan ng isang
bagay na gagamitin, ilan dito ay mga bilang, boolean, at mga salita o string sa wikang ingles.

**Halimbawa**
```kalawang
// Tagalog
si pangalan = "Maynila" ᜵
ipangalan edad = 2026 ᜵

sabihin pangalan ᜵
sabihin edad ᜵

// Using Baybayin Script
ᜐᜒ a = 15 ᜵
ᜐᜒ b = 25 ᜵
ᜐᜒ suma = a + b ᜵

ᜐᜊᜒᜑᜒᜈ᜔ suma ᜵
```

3. `Ay`
> Ang `ay` o `ᜀᜌ᜔` sa baybayin ay ginagamit upang maglagay ng isang bagay sa isang lalagyanan (variable/container). Kung sa programming, ito ay `assign operators`.
Ito ay pwedeng gamitin kapalit ng `=`.

**Halimbawa**
```kalawang
// Using Latin Tagalog
si pangalan ay "Maynila" ᜵
ipangalan edad ay 2026 ᜵

sabihin pangalan ᜵
sabihin edad ᜵

// Using Baybayin Script
ᜐᜒ a ᜀᜌ᜔ 15 ᜵
ᜐᜒ b ᜀᜌ᜔ 25 ᜵
ᜐᜒ suma = a + b ᜵

ᜐᜊᜒᜑᜒᜈ᜔ suma ᜵
```

4. `Pahingi`
> Ang `pahingi` o `ᜉᜑᜒᜅᜒ` sa baybayin ay ginagamit naman bilang paghingi ng `data` o isang bagay mula sa nagamit. Ginagamit ito karaniwan kasama ang lagayan (variable/container)
para paglagyan ng bagay na binigay ng nagamit.

**Halimbawa**
```
// Tagalog
si pangalan = pahingi("Anong pangalan mo? ") ᜵
sabihin ("Kamusta, " + pangalan) ᜵

// English
that name = ask("What is your name? ") ᜵
print ("Hello, " + name) ᜵

// Baybayin Script
ᜐᜒ ᜉᜅᜎᜈ᜔ = ᜉᜑᜒᜅᜒ("ᜀᜈᜓᜅ᜔ ᜉᜅᜎᜈ᜔ ᜋᜓ? ") ᜵
ᜐᜊᜒᜑᜒᜈ᜔ ("ᜃᜋᜓᜐ᜔ᜆ᜵ " + ᜉᜅᜎᜈ᜔) ᜵
```

> Ilan lamang ito sa mga pangkaraniwang magagamit ninyo, para sa karagdagang halimbawa, maaari nyong bisitahin ang [mga halimbawang ito](#📂-example-files) at sa susunod pa
gagawan ko na rin ng mas maayos pang paraan ng paggamit.
